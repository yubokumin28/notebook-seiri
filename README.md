# ノートまとめて整理 for Gemini Notebook

Gemini Notebook(notebook.google.com、旧 NotebookLM)のノートを、まとめて片付ける Chrome 拡張機能です。

- **まとめて削除**: ノートにチェックを付けて、1回で削除(1冊ずつ「︙ → 削除 → 確認」を押さなくてよい)
- **題名とカテゴリをまとめて変更**
- **ノートの中の重複した資料をまとめて削除**

外部とは通信しません。あなたの Chrome の中だけで動き、ノートの中身はどこにも送られません。

## 入れ方(5分)

1. このページの右の **Releases** から `notebook-seiri-1.8.1.zip` をダウンロードする
   (または緑の **Code** ボタン → **Download ZIP** で、中の `extension` フォルダを使う)
2. ZIP を右クリック → **すべて展開** で、フォルダにする
3. Chrome のアドレス欄に `chrome://extensions` と入れて開く
4. 右上の **デベロッパー モード** をオンにする
5. **パッケージ化されていない拡張機能を読み込む** を押し、手順2で展開したフォルダ(manifest.json が入っているフォルダ)を選ぶ
6. notebook.google.com を開くと、ノート一覧にチェック欄と下のバーが出ます。使い方はバーの「❔ 使い方」から

## 外し方(10秒)

1. `chrome://extensions` を開く
2. 「ノートまとめて整理 for Gemini Notebook」の **削除** を押す

それだけです。ノートにも Google アカウントにも何も残りません。展開したフォルダも消してかまいません。

## 注意

- 削除した Gemini Notebook のノートは元に戻せません。消す前にチェックしたノートを確認してください
- 日本語表示の Gemini Notebook で使う前提です
- Gemini Notebook の画面が変わると、動かなくなることがあります
